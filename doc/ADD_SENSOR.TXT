How to add new sensor
=====================

Since Arduino program is basically a C++ program with little difference, better
understanding of C++ programming language can help modify this program.

In the tutorial, we add a new sensor called "xyzzy" into the program for
a simple example.  The procedure will be described step by step.

1. In file "Arduino_Portable_v1.ino" -> namespace "Sensor" -> enum "Identifier",
add identifier for the sensor.
	enum Identifier {
		SHT40 = 1,
		BME280 = 2,
		PMS5003 = 3,
		XYZZY = 4,
		number
	};

2. In "config_device.h.example" and "config_device.h", add a configuration
option, such as:
	#define ENABLE_SENSOR_XYZZY

3. In "config_device.h.example" and "config_device.h", add an entry in default
parameter as DEFAULT_SENSORS, such as:
	#define DEFAULT_SENSORS { \
		[0] = std::nullopt, \
		[SHT40] = std::nullopt, \
		[BME280] = std::nullopt, \
		[PMS5003] = std::nullopt \
		[XYZZY] = 12345 \
	}

4. In file "Arduino_Portable_v1.ino" -> session of "Sensor", add "#include"
statements and defined variables for the libraries of the sensor.

5. In namespace "Sensor" -> array "models", add information of elements.
	Model const models[number] = {
		[0] = {"(PLACEHOLDER)", {}},
		[SHT40] = {
			"SHT40",
			{
				{"SHT40_temperature", "Temperature", "\u2103"},
				{"SHT40_humidity", "Humidity", "%"}
			}
		},
	...skip...
		[XYZZY] = {
			"XYZZY",
			{
				{"XYZZY_value1", "Value One", "UnitA"},
				{"XYZZY_value2", "Value Two", "UnitB"}
			}
		}
	};
In the above example, the first string in the [XYZZY] session is the name of
the sensor. The first field of the following array ("XYZZY_value1" and
"XYZZY_value2") are the upload name of the elements; the second field is the
human-readable name of the element; and the third field is the unit.

6. In namespace "Sensor" -> function "setup",
add initialization of the sensor if necessary.
	#if defined(ENABLE_XYZZY)
		if (parameters[XYZZY]) {
			while (!xyzzy.begin("some other parameters...")) {
				Display::println("xyzzy not found");
			}
			Display::println("xyzzy found");
		}
	#endif

7. In struct "Data", add data fields for the sensor.
	class Data {
	protected:
		DateTime time;
		DateTime device_time;
		#if defined(ENABLE_SENSOR_SHT40)
			float SHT40_temperature;
			float SHT40_humidity;
		#endif
	...skip...
		#if defined(ENABLE_SENSOR_XYZZY)
			float XYZZY_value1;
			float XYZZY_value2;
		#endif

8. In method "Data::to_CSV", add writing values to CSV of the sensor.
	#if defined(ENABLE_SENSOR_XYZZY)
		if (Sensor::parameters[Sensor::XYZZY])
			s = s + ',' + XYZZY_value1 + ',' + XYZZY_value2;
	#endif

9. In method "Data::display", display values to OLED display.
	#if defined(ENABLE_SENSOR_XYZZY)
		if (Sensor::parameters[Sensor::XYZZY]) {
			Monitor.print(XYZZY_value1, 3);
			Monitor.println("UnitA");
			Monitor.print(XYZZY_value2, 0);
			Monitor.println("UnitB");
		}
	#endif

10. In method "Data::measure", receive data from the sensor and store into
member variables of "Data" instance.
	#if defined(ENABLE_SENSOR_SHT40)
		if (Sensor::parameters[Sensor::SHT40]) {
			int const parameter = parameters[XYZZY].value();
			XYZZY_value1 = xyzzy.get_value1(parameter);
			XYZZY_value2 = xyzzy.get_value2(parameter);
		}
	#endif
